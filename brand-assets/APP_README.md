# Brand Assets Interactive App

This directory contains a standalone static viewer for the 54 SVG assets and 54 source prompts. Deploy Vercel project rootDirectory = `brand-assets` on preview branch `brand-assets/three-site-library-v1` or run any static file server from this directory. The code does not alter the three website source files.

Features: B2W/JasonAI/Clara/shared tabs, section/depth/search/status filters, six-column card catalog, golden ratio focus stage, one-by-one pagination, prompt modal, SVG download, URL deep links (`?asset=JAI-04-03`), locally saved approve/revise decisions with JSON export, responsive mobile view and reduced-motion support. Reviews persist locally on each device only and must be exported to share.

All assets are illustrative; approve before publication. The earlier `04-explorer/index.html` remains available as a legacy example.
